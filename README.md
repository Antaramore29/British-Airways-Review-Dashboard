# British-Airways-Review-Dashboard
A dynamic, filterable Tableau dashboard that explores passenger reviews for British Airways from 2016 to 2023. This project demonstrates end-to-end data visualization, offering insights into customer satisfaction by time, location, and aircraft type.

# ✈️ British Airways Review Dashboard – Tableau

This project is a fully interactive Tableau dashboard designed to explore and analyze customer review data for British Airways, built from two datasets: one with 8+ review metrics and another with country mapping data. The dashboard enables dynamic filtering, rating comparisons, and insights into aircraft, traveler types, and regions.

## Tools & Technologies
- Tableau Public
- Data Cleaning in Excel
- Calculated Fields, Parameters & Filters
- Interactive Visualizations & Tooltips

## Key Features
- Toggle between metrics like **Cabin Staff Service**, **Seat Comfort**, **Entertainment**, etc., using a dynamic parameter picker.
- View **Average Ratings by Month**, **Country**, and **Aircraft**, all updated based on selected filters.
- Filters for **Seat Type**, **Traveler Type**, **Aircraft**, and **Continent**, with visuals acting as filters too.
- Summary KPIs at the top for 7 key service aspects (Cabin, Food, Ground, etc.)
- Clean, responsive dashboard layout using floating containers and custom color styling.

## Business Insights
- Aircrafts like Boeing 747-400 had the highest average ratings (~4.7).
- Ratings vary significantly by **country**, **traveler type**, and **seat class**.
- Key areas for improvement: **Entertainment (1.4)** and **Cabin Staff Service (3.3)**.
